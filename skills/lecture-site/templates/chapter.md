도입부는 첫 '##' 앞에 씁니다. 구체적 인물과 장면 하나로 시작합니다. 가상 인물이면 "(가상 회사)"처럼 바로 밝힙니다.

장면 끝에 독자가 품을 질문을 한 줄로 둡니다. 그런 다음 이 장에서 무엇을 볼지 한 문단으로 예고합니다.

## 꼭지 제목은 주장 문장 그대로, 숫자를 넣어서 {#a-01}

```fig a-01-a
type: stat
tone: dark
value: 51,071
label: 입력 토큰
grid: 51
grid_note: 한 칸 1,000토큰
mark: 내가 친 한 줄
caption: 그림이 말하는 것을 한 문장으로(화면 낭독기와 alt 에 쓰임)
```

설명 문단. 사실 문장 끝마다 근거 id 를 붙입니다.[^F-0001] **처음 나오는 용어**는 굵게 쓰고 바로 한 문장으로 풀어 줍니다.

모르는 것은 모른다고 씁니다. 잰 값과 추정은 구분합니다.

### 같은 꼭지의 두 번째 그림(설명용) 제목

```fig a-01-b
type: bars
unit: k
steps: yes
- Skills | 9.9 | 9.9k
- Memory files | 6.8 | 6.8k
- System prompt | 3.4 | 3.4k | hl
caption: 입력 전부터 들어 있는 세 항목의 크기
```

:::cond 조건과 한계
- 잰 환경과 날짜, 반복 횟수 [^F-0001]
- 가상 장면이면 그렇다고
- 확인하지 못한 것
:::
